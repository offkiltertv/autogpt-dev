## Phase 2: Creator Discovery Surfaces

## Current discovery paths
1. Homepage content rails (Elementor + Beeteam blocks)
2. Creator archives/channel pages
3. Site search
4. Arcana category pages (`arcana`, `premonitions`, `outcomes`)
5. Subscription surfaces (channel follow patterns)

## Where high-scoring creators should surface first
1. Homepage: `🔮 Featured Readers` (primary)
2. Arcana category archives: creator metadata visible on cards
3. Search results: prioritize channels with complete profile assets
4. Creator directory: Arcana Readers page linked from Arcana nav tree
5. Subscription prompts: only for verified/claimed profiles

## Exposure rule by score
- `80+`: Eligible for homepage rail + outreach + featured rotation.
- `60-79`: Directory + category pages; not permanent homepage placement.
- `<60`: Directory only until profile quality improves.

## Phase 3: Channel Ownership Tiers

## Tier definitions
| Tier | Name | Meaning |
|---|---|---|
| Tier 1 | Unclaimed Imported Creator | Imported creator identity exists, no verified owner |
| Tier 2 | Verified Creator | Identity verification completed, ownership not fully transferred |
| Tier 3 | Claimed Creator | OffKilter account linked and creator manages profile/channel |

## Visual treatment (no code required)
| Tier | Badge Label | Card Treatment | CTA |
|---|---|---|---|
| Tier 1 | `Imported` | Neutral styling, attribution-first | `Claim this profile` |
| Tier 2 | `Verified` | Confidence indicator + profile completeness prompts | `Complete channel setup` |
| Tier 3 | `Claimed` | Full creator presentation in rails and featured surfaces | `Subscribe` |

## Phase 4: Arcana Platform Identity Interconnection

## Target user path
1. Homepage `🔮 The Arcana` rail ->
2. `🔮 Featured Readers` rail ->
3. Arcana creator profile ->
4. Premonitions/Outcomes archives ->
5. Subscribe and return session

## Navigation structure
- `Arcana`
- `Premonitions`
- `Outcomes`
- `Readers`

## Interconnection rules
1. Every Arcana video card should expose creator + category.
2. Every Arcana creator page should link back to Arcana archives.
3. Readers directory should link to creator pages, not isolated static profiles.
4. Featured Readers should be refreshed from score changes, not manually frozen.

## Operating cadence
- Weekly: review top 10 placement.
- Monthly: re-score top 25 and rotate.
- Quarterly: expand beyond top 25 if claim throughput supports it.
