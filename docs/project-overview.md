# OffKilter.TV Project Overview

## Mission
OffKilter.TV is an independent creator platform combining:
- Video
- Community
- Forums
- Memberships
- Discussion
- Content curation

The platform objective is to use existing WordPress-based systems to deliver creator-owned discovery, interpretation, and engagement without unnecessary stack replacement.

## Primary Systems
- WordPress: application foundation and content runtime
- VidMov: media-centric theme and creator/video UX layer
- wpForo: forum and long-form discussion layer
- ARMember: memberships, access tiers, subscription controls
- myCred: points, ranks, incentives, reward logic
- Arcana: curated knowledge-vault ingestion and discussion plugin

## Product Direction
- Keep YouTube as host where applicable, embed and contextualize on OffKilter.
- Build indexable pages that combine media + interpretation + discussion.
- Drive retention through forum identity and recurring publishing cadence.
- Expand monetization through memberships and premium discussion layers.

## Operating Principles
- Preserve and leverage existing stack first.
- Ship in reversible increments.
- Document architecture and operations as first-class deliverables.
- Treat production stability as a gate for all feature work.
