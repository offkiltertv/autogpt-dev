## 2) Creator Profile Enhancement Audit

## Existing profile-capable fields (VidMov/Beeteam user meta)
- `beeteam368_user_profile_id`
- `beeteam368_user_avatar`
- `beeteam368_user_channel_banner`
- `description`
- `beeteam368_introduce_yourself`
- `beeteam368_subscribe_count`
- `beeteam368_member_verification`
- privacy/subscription metadata (`beeteam368_privacy_*`, `beeteam368_subscribe_data`)

## Current gaps
- Imported Arcana author accounts (IDs 87/88/89) have no profile ID, no avatar/banner, empty bio.
- Arcana category terms only carry membership meta; no enriched archive descriptions.
- Source-inventory creators are mostly not yet mapped to OffKilter creator term IDs.

## Minimum creator profile standard (recommended)
1. Display name aligned with creator handle.
2. Avatar set (`beeteam368_user_avatar`).
3. Channel banner set (`beeteam368_user_channel_banner`).
4. Bio/description populated (2-4 sentence summary + disclaimer-aware tone).
5. Canonical channel/profile URL published.
6. Source attribution note (imported metadata origin).

## 3) Featured Arcana Readers (Homepage Rail)

## Existing widget support
- Widget: `beeteam368_channel_extensions` (VidMov - Channel Extensions)
- Supported sort modes:
  - `most_subscriptions`
  - `highest_reaction_score`
- Rendering template: `item-marguerite-author-widget.php`
- Displays:
  - creator avatar
  - creator name
  - verification icon
  - subscribers count (when ordered by `most_subscriptions`)

## Limitation
- Widget does **not** natively show each creator’s latest video in the same card.

## Practical rail design
- Rail title: `🔮 Featured Readers`
- Source: `beeteam368_channel_extensions`
- Order: `most_subscriptions`
- Items: `6`
- Pagination: `loadmore-btn`
- Pair with adjacent `beeteam368_post_extensions` Arcana video rail to surface latest videos.
